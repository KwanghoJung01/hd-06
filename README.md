# HD-06: 프로젝트 협업 대시보드

HD-06는 팀 프로젝트의 진행 상황, 문서 공유, 일정 관리, 핵심 지표를 한 화면에서 확인할 수 있도록 만든 대시보드입니다. 

Google Docs와 같은 문서 기반 협업 환경을 중심으로 구성되어 있으며, 회의록, 공유 문서, 일정, 마일스톤, 진행률을 한 번에 정리해 팀원들이 실시간으로 업무 상태를 파악할 수 있도록 설계했습니다.

## 주요 기능
- 프로젝트 전체 진행률 및 KPI 요약
- 주요 업무별 상태 추적
- 간트차트 기반 일정 관리
- 마일스톤 및 리스크 점검
- 협업 문서 링크 통합 관리
- GitHub Pages를 활용한 간단한 배포 구조

## 프로젝트 목적
프로젝트가 커질수록 회의록, 문서, 일정, 업무 현황이 분산되기 쉽습니다. 이 대시보드는 팀이 각 정보를 한 곳에서 확인하고, 업무 우선순위를 빠르게 판단하며, 협업 효율을 높이는 데 초점을 두고 있습니다.

## 특징
- 단일 HTML 파일 기반으로 구성되어 있어 배포와 수정이 간단함
- 설정값만 변경하면 대시보드 데이터와 구조를 손쉽게 재사용 가능
- 팀 공유용 화면으로 적합하며, 프로젝트 운영 현황을 시각적으로 전달하기 편함

## 사용 방법
1. 저장소를 클론합니다.
2. 브라우저에서 index.html 파일을 직접 열어 확인합니다.
3. GitHub Pages로 배포하여 팀 공유용 대시보드로 사용할 수 있습니다.

## 활용 예시
- 프로젝트 진행 상황 공유
- 회의 후 업무 점검
- 팀 내부 보고용 대시보드
- 문서 연동 기반 협업 관리를 위한 중심 화면

본 프로젝트는 문서 중심 협업을 지원하는 팀 대시보드로, 프로젝트 관리의 가시성을 높이는 데 목적이 있습니다.
