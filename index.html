회의록 (구글 문서)

정기·수시 회의 기록을 이 문서 하나에 누적 작성합니다.

Google Docs› HD 프로젝트› 회의록 (Meeting Notes)

1회의록 작성 규칙

  1. 최신 회의가 위로 오도록 문서 맨 위에 새 회의를 추가합니다.
  2. 제목 형식: [YYYY-MM-DD] 회의명 / 작성자
  3. 항목 순서: 참석자 → 안건 → 결정사항 → 액션아이템(담당·기한)
  4. 액션아이템은 담당자를 @이름 으로 멘션해 알림이 가도록 합니다.
  5. 수정은 제안 모드가 아닌 직접 편집, 삭제 대신 취소선을 사용합니다.
공유 권한 안내 — 링크를 가진 프로젝트 참여자 전원(30명)이 열람·편집할 수 있습니다. 외부 공유가 필요하면 PM에게 먼저 요청해 주세요.

공유 폴더 (구글 드라이브)

프로젝트 기간 동안 모든 파일을 이 폴더에서 올리고 내려받습니다.

Google Drive› 공유 문서함› HD프로젝트_공유폴더

2파일 올리기 / 받아가기

  1. 올리기 — [공유 폴더 열기] → 해당 하위 폴더로 이동 → 파일을 창 안으로 끌어다 놓기(또는 + 신규 › 파일 업로드).
  2. 받아가기 — 파일 선택 → 마우스 오른쪽 클릭 › 다운로드. 여러 개는 Ctrl(Mac은 ⌘)로 다중 선택 후 한 번에 받습니다.
  3. 파일명 규칙 — YYYYMMDD_문서명_담당자_v1.0 (예: 20260812_요구사양서_홍길동_v1.2)
  4. 버전 — 같은 파일을 고칠 때는 새 파일을 만들지 말고, 기존 파일 위에 같은 이름으로 올려 버전 관리에 쌓이게 합니다.
  5. 대용량 — 500MB 이상 3D·영상 파일은 압축 후 05_영상_이미지 폴더에 올리고 회의록에 등록 사실을 남깁니다.
주의 — 원본 파일의 이동·삭제·이름 변경은 다른 팀원에게도 그대로 반영됩니다. 남의 파일은 수정하지 말고 사본을 만들어 사용해 주세요. 사내 대외비 자료는 담당 부서 승인 후 업로드합니다.
